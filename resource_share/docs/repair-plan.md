## 游戏验收

| 场景 | 预期 |
| --- | --- |
| A 有 10 石头；玩家及 B 没有石头 | B 建造菜单正确计入 10 个 |
| B 建造消耗 N 个石头的建筑（N ≤ 10） | A 剩余 10 − N；没有物品复制或重复扣除 |
| 成本超过公会现有总量 | 正常提示不足，不能免费建造 |

| B 为新建且无箱子的基地 | 可使用同公会已有基地材料 |
| 新建箱子、修改库存、拆除箱子 | 及时刷新，拆除后没有幽灵库存 |
| 传送、返回标题、重新进档 | 无旧对象引用、错误合并或崩溃 |
| 快速堆叠和物品检索设备 | 原有物品整理行为正常 |
